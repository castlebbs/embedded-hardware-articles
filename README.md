# Wiki Blog Articles

This repository contains a collection of technical blog articles that were previously published on blog.ombrepixel.com. The website is no longer accessible, so these articles are being migrated here for preservation and reference. More articles will be added as the migration continues.

## Available Articles

- **scapy-hping3.md**: Comparison between Scapy and hping3 for analyzing TCP Initial Sequence Number (ISN) distribution, including code samples and performance discussion.
- **scapy-hping3.fr.md**: French version of the Scapy vs hping3 ISN spectrograph article.
- **smartcard-reader.md**: Guide and technical notes on using and programming smartcard readers.
- **smartcard-reader.fr.md**: French version of the smartcard reader article.

## About

All articles are authored by David Robert (castlebbs) and are being preserved here for archival and educational purposes. More articles will be added as they are recovered and converted from the original blog.
