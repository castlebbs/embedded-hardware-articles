# Wiki Blog Articles

This repository contains a collection of technical blog articles that were previously published on blog.ombrepixel.com and nexten.ie. The websites are no longer accessible, so these articles are being preserved here for archival and educational purposes.

## Available Articles

- [ESP32: Firmware dumping and flash extraction](https://github.com/castlebbs/embedded-hardware-articles/blob/main/esp32-firmware-dump.md): A practical walkthrough showing how to dump firmware from ESP32-based devices using the serial bootloader and tools such as esptool.py. Covers identifying flash layout, reading/merging partitions, handling encrypted images and common pitfalls during extraction.

- [ESP32: Secure Boot and Flash Encryption](https://github.com/castlebbs/embedded-hardware-articles/blob/main/esp32-secureboot.md): Explains ESP32 secure boot and flash encryption mechanisms, key management, and how they affect firmware extraction and device recovery. Includes a step-by-step guide to enable/verify secure boot, practical examples and mitigation strategies.

- [Scapy vs hping3: ISN spectrograph (network analysis)](https://github.com/castlebbs/embedded-hardware-articles/blob/main/scapy-hping3.en.md): A comparison between Scapy and hping3 for analyzing TCP Initial Sequence Number (ISN) distributions. Contains code samples, methodology, performance measurements and discussion about which tool is better suited for different tasks.

- [Smartcard reader: CP8 and carte bleue exploration](https://github.com/castlebbs/embedded-hardware-articles/blob/main/smartcard-reader.md): Guide and technical notes on using and programming smartcard readers (Bull CP8). Describes wiring, the TLP224 protocol, Linux driver usage, examples for reading a carte bleue (credit card) for educational/archival purposes and included scripts used to decode card data.

## About
